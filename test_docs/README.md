# Test Docs

This directory contains evaluation assets and helper scripts for the Legal Co-Pilot.

Structure:
- `baseline/`
  - `documents/`: small regression dataset used for smoke tests and benchmark captures
  - `prompts/`: extraction, review, and Q&A inputs for the baseline dataset
- `hard/`
  - `documents/`: larger or more varied DOCX inputs
  - `prompts/`: harder extraction, review, and Q&A prompts
- `scripts/`
  - runnable test and benchmark helpers
- `docs/`
  - expected results, evaluation workflow, and grading rubric
- `templates/`
  - result templates for reporting or poster-ready summaries
